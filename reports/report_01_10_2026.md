# Fitur Follow & Unfollow (Following & Followers)
- Telah dibuat migration untuk tabel `followers` (menyimpan id, follower_id, followed_id, created_at, updated_at).
- Model `User` telah di-update dengan relasi `followers()` dan `following()`.
- API endpoint baru telah dibuat dan didaftarkan:
  - `POST /api/follow/{user_id}`: Follow akun user
  - `POST /api/unfollow/{user_id}` atau `DELETE /api/follow/{user_id}`: Unfollow akun user
  - `GET /api/user/{user_id}/followers`: List user yang memfollow user tersebut
  - `GET /api/user/{user_id}/following`: List user yang difollow oleh user tersebut
- Response data API untuk Detail User (`UserController@detailUser`) dan Store Profile (`StoreController@showStoreProfile`) telah ditambahkan field `total_followers`, `total_following`, dan `is_followed_by_me` untuk mengakomodir kebutuhan UI dan state tombol Ikuti/Mengikuti.

======
## Update Format Response Followers & Following (01-10-2026)
- Menyesuaikan *output* nilai `avatar` pada API `/api/user/{user_id}/followers` dan `/api/user/{user_id}/following`. 
- `avatar` kini mengembalikan URL gambar *full path* (menggunakan fungsi `asset()` Laravel), dengan prioritas: Foto Profil User -> Foto Logo Toko -> null.

### Contoh Response API Baru:

**1. `POST /api/follow/{user_id}` atau `POST/DELETE /api/unfollow/{user_id}`**
```json
{
    "message": "Berhasil follow user" 
}
```

**2. `GET /api/user/{user_id}/followers` dan `GET /api/user/{user_id}/following`**
```json
{
    "message": "success",
    "data": [
        {
            "id": 2,
            "name": "Budi Santoso",
            "avatar": "http://domainanda.com/assets/image/customers/profile/17150123_budi.jpg",
            "is_followed_by_me": true
        },
        {
            "id": 5,
            "name": "Toko Berkah",
            "avatar": "http://domainanda.com/assets/image/customers/logo_toko/1723145_toko.png",
            "is_followed_by_me": false
        },
        {
            "id": 8,
            "name": "User Tanpa Foto",
            "avatar": null,
            "is_followed_by_me": false
        }
    ]
}
```
*Catatan untuk Frontend:* 
Untuk list Followers/Following, Backend mengirimkan data standar. Silakan lakukan proses *sorting* mandiri jika terdapat akun current user (akun "Anda") dalam *list* untuk diletakkan di urutan paling atas dan diberikan UI khusus.

======
## Update Endpoint Universal Profile (01-10-2026)
- Modifikasi endpoint `GET /api/store/{id_user}` agar tidak me-return *error 404* ketika `id_user` yang dituju bukanlah sebuah toko.
- Merubah perilaku endpoint menjadi **Universal Profile** (menampilkan baik toko maupun user biasa).
- Jika `id_user` adalah *user* biasa (tidak memiliki toko):
  - `is_toko` dikembalikan bernilai `false`.
  - `nama_store` otomatis diganti menggunakan *nama lengkap user*.
  - `foto_toko` otomatis menggunakan *foto profil user*.
  - Statistik produk toko (`rating_toko`, `total_produk_aktif`, `total_transaksi_selesai`, `total_ulasan`) diatur nilainya menjadi `0`.
  - `deskripsi_toko` mengembalikan pesan "Pengguna ini adalah pengguna biasa dan tidak menyewakan produk".
- Jika `id_user` adalah sebuah toko:
  - `is_toko` dikembalikan bernilai `true`.
  - Semua kalkulasi rating, pesanan, dan jumlah produk aktif tetap berjalan dengan normal sebagaimana mestinya.

======
## Revisi Logic URL Avatar pada List Followers & Following (01-10-2026)
- Menambahkan parameter `name_store` ke dalam query select untuk API `GET /api/user/{user_id}/followers` dan `GET /api/user/{user_id}/following`.
- Memperbarui prioritas *fallback* URL gambar `avatar` berdasarkan tipe *user* sesuai dengan kebutuhan UI baru:
  1. Jika user merupakan mitra/toko (`is_toko == true`), sistem akan memprioritaskan mengambil foto logo toko (`foto_toko`). Jika logo toko kosong/null, baru melakukan *fallback* ke foto profil pribadi (`foto`).
  2. Jika user adalah pengguna biasa (bukan toko), sistem langsung menggunakan foto profil pribadi (`foto`).
  3. Jika semua opsi kosong, maka field `avatar` akan me-return nilai `null` seperti biasa (untuk *placeholder default* di sisi Frontend).
