# Report Permintaan API Fitur Rekomendasi Wisata & Berita Terkini (Blog / Artikel)
**Tanggal**: 15-10-2026

## 1. Konteks Kendala & Latar Belakang Perubahan
Sebelumnya pada aplikasi mobile (`lib/layouts/layout_dashboard.dart`), section **Rekomendasi Wisata** dan **Berita Terkini** masih menggunakan dummy data lokal (`DummyProductApiResponse.getDataWisata()` dan `DummyProductApiResponse.getDataBerita()`). Selain itu, ketika kartu artikel/wisata diklik, aplikasi langsung mengarahkan pengguna ke browser eksternal via `url_launcher`.

Sesuai permintaan kebutuhan baru, backend kini telah menyediakan infrastruktur REST API lengkap dengan sistem blog dinamis dari database, mendukung preview dashboard, halaman daftar lengkap ("Lihat Semua") dengan sorting dan filtering komprehensif, serta halaman detail artikel bergaya blog yang secara otomatis menambah jumlah penayangan (*views count*).

---

## 2. Ringkasan Implementasi Backend

1. **Skema Database Terpadu (`articles`)**:
   - Dibuat tabel tunggal `articles` yang efisien dan terindeks dengan kolom pembeda `tipe` (`'wisata'` atau `'berita'`).
   - Menyimpan judul, slug SEO, cover gambar/thumbnail, deskripsi singkat, konten artikel lengkap (LongText), lokasi wisata, nama & link sumber eksternal, referensi author/pengunggah, status publikasi, dan penghitung pembaca (`views_count`).
2. **Seeding Data Nyata (950 Konten)**:
   - Data Rekomendasi Wisata diambil dan diimpor sebanyak **450 data** dari `public/detik_wisata_450.json`.
   - Data Berita Terkini diambil dan diimpor sebanyak **500 data** dari `public/bbc_wisata_500.json`.
   - Total **950 data aktif** telah terdistribusi ke dalam database dengan timestamp dinamis sehingga seluruh filter rentang waktu (*hari ini*, *minggu ini*, *bulan ini*, *tahun ini*) dapat diuji secara optimal.
3. **Standarisasi Format Waktu Indonesia (WIB)**:
   - Setiap objek data artikel menyertakan representasi tanggal & jam lengkap Indonesia:
     - `tanggal_upload`: Contoh `"15 Oktober 2026"`
     - `waktu_upload`: Format jam & zona waktu, contoh `"13:02 WIB"`
     - `waktu_lalu`: Human-readable time ago bahasa Indonesia, contoh `"2 jam yang lalu"` / `"Kemarin"`
     - `created_at`: Format ISO 8601 (`"2026-10-15T06:02:00.000000Z"`) untuk fleksibilitas manipulasi di mobile.
4. **Endpoint Publik & Admin CMS**:
   - Tersedia endpoint publik untuk konsumen mobile (list & detail).
   - Setiap kali endpoint detail (`GET /api/wisata/{id}` atau `GET /api/berita/{id}`) diakses oleh user, `views_count` otomatis bertambah +1.
   - Tersedia endpoint CRUD CMS untuk Admin/Developer (`POST`, `PUT`, `DELETE`).

## 3. Spesifikasi Skema Database (`articles`)

| Nama Kolom | Tipe Data | Keterangan & Aturan |
| :--- | :--- | :--- |
| `id` | `BIGINT UNSIGNED` | Primary Key, Auto Increment |
| `tipe` | `ENUM('wisata', 'berita')` | Kategori entitas konten |
| `judul` | `VARCHAR(255)` | Judul berita atau nama tempat wisata |
| `slug` | `VARCHAR(255)` | URL-friendly slug, nullable |
| `gambar` | `VARCHAR(255)` | URL gambar atau path storage backend |
| `deskripsi_singkat` | `TEXT` | Sinopsis/ringkasan untuk card tampilan mobile |
| `konten` | `LONGTEXT` | Isi lengkap artikel blog / informasi detail destinasi |
| `lokasi` | `VARCHAR(255)` | Lokasi destinasi wisata (Nullable, khusus `wisata`) |
| `sumber_url` | `VARCHAR(500)` | Tautan web asli / portal eksternal (Nullable) |
| `sumber_nama` | `VARCHAR(100)` | Nama portal sumber (misal: "Detik Travel", "BBC News") |
| `author_id` | `BIGINT UNSIGNED` | Foreign Key mengarah ke `users.id` (Author pengunggah) |
| `status` | `ENUM('published', 'draft', 'archived')` | Default: `'published'` |
| `views_count` | `INT UNSIGNED` | Default: `0`, naik otomatis saat endpoint detail dipanggil |
| `created_at` | `TIMESTAMP` | Waktu dibuat / tanggal rilis artikel |
| `updated_at` | `TIMESTAMP` | Waktu terakhir diperbarui |

## 4. Parameter Filtering & Sorting yang Didukung

Endpoint list (`/api/wisata` dan `/api/berita`) mendukung parameter query string berikut:

| Parameter | Tipe Data | Opsi Nilai | Penjelasan Fungsi |
| :--- | :--- | :--- | :--- |
| **`limit`** | `Integer` | Misal `5` atau `6` | Membatasi jumlah record yang dikembalikan (digunakan pada dashboard preview). Jika diisi, mengabaikan parameter `page`. |
| **`sort_by`** | `String` | • `terbaru` / `latest` *(Default)*<br>• `terlama` / `oldest`<br>• `terpopuler` / `popular`<br>• `a_z`<br>• `z_a` | • `terbaru`: `created_at DESC`<br>• `terlama`: `created_at ASC`<br>• `terpopuler`: `views_count DESC`<br>• `a_z`: Abjad `judul ASC`<br>• `z_a`: Abjad `judul DESC` |
| **`filter_waktu`** | `String` | • `semua` *(Default)*<br>• `hari_ini`<br>• `minggu_ini`<br>• `bulan_ini`<br>• `tahun_ini` | Memfilter artikel berdasarkan rentang waktu pembuatan |
| **`lokasi`** | `String` | Contoh: `Malang`, `Bromo`, `Batu` | Pencarian parsial berdasarkan kota/provinsi destinasi *(khusus wisata)* |
| **`search`** | `String` | Kata kunci bebas | Mencari kemunculan teks pada `judul`, `deskripsi_singkat`, atau `konten` |
| **`page`** | `Integer` | Default: `1` | Nomor halaman data (pagination) |
| **`per_page`** | `Integer` | Default: `10` | Jumlah artikel per halaman (pagination) |

## 6. Panduan Integrasi Mobile Flutter

### A. Definisi Model Dart (`ArticleModel`)
Buat atau perbarui model data pada file `lib/models/article_model.dart`:

```dart
class ArticleModel {
  final int id;
  final String tipe;
  final String judul;
  final String slug;
  final String gambar;
  final String deskripsiSingkat;
  final String konten;
  final String? lokasi;
  final String? sumberUrl;
  final String? sumberNama;
  final int viewsCount;
  final String tanggalUpload;
  final String waktuUpload;
  final String waktuLalu;
  final String createdAt;
  final ArticleAuthor? author;

  ArticleModel({
    required this.id,
    required this.tipe,
    required this.judul,
    required this.slug,
    required this.gambar,
    required this.deskripsiSingkat,
    required this.konten,
    this.lokasi,
    this.sumberUrl,
    this.sumberNama,
    required this.viewsCount,
    required this.tanggalUpload,
    required this.waktuUpload,
    required this.waktuLalu,
    required this.createdAt,
    this.author,
  });

  factory ArticleModel.fromJson(Map<String, dynamic> json) {
    return ArticleModel(
      id: json['id'] ?? 0,
      tipe: json['tipe'] ?? '',
      judul: json['judul'] ?? '',
      slug: json['slug'] ?? '',
      gambar: json['gambar'] ?? '',
      deskripsiSingkat: json['deskripsi_singkat'] ?? '',
      konten: json['konten'] ?? '',
      lokasi: json['lokasi'],
      sumberUrl: json['sumber_url'],
      sumberNama: json['sumber_nama'],
      viewsCount: json['views_count'] ?? 0,
      tanggalUpload: json['tanggal_upload'] ?? '',
      waktuUpload: json['waktu_upload'] ?? '',
      waktuLalu: json['waktu_lalu'] ?? '',
      createdAt: json['created_at'] ?? '',
      author: json['author'] != null ? ArticleAuthor.fromJson(json['author']) : null,
    );
  }
}

class ArticleAuthor {
  final int id;
  final String nama;
  final String email;
  final String foto;

  ArticleAuthor({
    required this.id,
    required this.nama,
    required this.email,
    required this.foto,
  });

  factory ArticleAuthor.fromJson(Map<String, dynamic> json) {
    return ArticleAuthor(
      id: json['id'] ?? 0,
      nama: json['nama'] ?? 'Admin KampSewa',
      email: json['email'] ?? '',
      foto: json['foto'] ?? '',
    );
  }
}
```
