**Laporan Pembaruan API - 3 Oktober 2026**

**Fitur:** API Riwayat Transaksi (Pesanan)
**Status:** Selesai
**Endpoint:** `GET /api/riwayat`

**Deskripsi:**
Telah dilakukan pembaruan pada endpoint `GET /api/riwayat` agar bisa digunakan langsung oleh tim Frontend (GetX) pada halaman `LayoutRiwayat`. 

- **Parameter:** 
  Endpoint ini sekarang mendukung parameter opsional `status` (sebelumnya `tipe_riwayat`) untuk melakukan filter berdasarkan "Belum Bayar", "Pengambilan", "Berlangsung", "Selesai", dan "Dibatalkan". Jika `status` tidak dikirim, API akan membalikkan semua riwayat dari pengguna tersebut.
- **Data Array:** 
  API sekarang mengembalikan data riwayat pesanan dalam bentuk **Array of Objects** di dalam key `data`, sehingga cocok untuk me-render list di UI Flutter (bukan cuma satu objek/data pertama seperti sebelumnya).
- **Group Checkout:** 
  Jika pengguna men-checkout banyak produk sekaligus (dalam 1 struk penyewaan), maka API otomatis menampilkan produk utamanya saja ditambah key `"qty_produk_lain"` agar desain card transaksi di aplikasi terlihat rapi.

======
**Update Lanjutan (3 Oktober 2026)**
- Ditambahkan *field* baru `"metode"` di dalam response object array pada `GET /api/riwayat`.
- Field ini bernilai *string* (misal: "Transfer" atau "COD") yang bisa dipakai frontend untuk menyembunyikan tombol "Bayar Sekarang" apabila status pesanan adalah COD.

**Contoh Update Response JSON:**
```json
{
    "success": true,
    "message": "Berhasil mengambil riwayat transaksi",
    "data": [
        {
            "id_transaksi": 120,
            "nama_toko": "Eiger Store",
            "...": "...",
            "status_transaksi": "Belum Bayar",
            "metode": "COD",
            "rekening_bank": "1234567890",
            "nama_bank": "BCA"
        }
    ]
}
```
