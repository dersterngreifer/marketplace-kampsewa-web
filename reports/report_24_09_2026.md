# Report: Implementasi Fitur Like / Favorite Produk
**Tanggal:** 24 September 2026
**Kepada:** Tim Frontend
**Dari:** Tim Backend

Halo Tim Frontend,

Permintaan untuk fitur "Like/Love" produk telah berhasil kami selesaikan dan sudah *live* di sisi Backend. Seluruh spesifikasi yang Anda butuhkan telah terpenuhi.

Berikut rincian dari implementasinya:

## 1. Skema Database
- Telah ditambahkan *table* pivot baru bernama produk_likes.
- Tabel ini menyimpan id_user dan id_produk dengan aturan *unique* (satu user hanya bisa melike produk yang sama maksimal satu kali). 

## 2. Pembaruan Endpoint API Produk (Response Payload)
Pada seluruh endpoint API yang menampilkan data produk (seperti list produk, pencarian, detail produk, keranjang, dll.), kami telah menambahkan 2 buah *key* di dalam JSON response sesuai dengan permintaan:
1. 	otal_likes (Integer): Jumlah total user yang menyukai produk.
2. is_liked (Boolean): Bernilai 	rue jika user yang mengirim *Request* (via token) sudah melike produk, dan bernilai alse jika belum (atau diakses sebagai guest / tanpa Bearer Token).

**Contoh Response Terkini:**
\\\json
{
  "id_produk": 1,
  "nama_produk": "Tenda Eiger",
  "harga_sewa": 50000,
  // ... field lainnya ...
  "images": [
      // ...
  ],
  "total_likes": 142,
  "is_liked": true
}
\\\

## 3. Endpoint API Baru (Toggle Like/Unlike)
Kami menyediakan Endpoint Action yang bisa Anda *hit* untuk mengeksekusi Like atau Unlike. Sistem otomatis membatalkan (*unlike*) apabila *button* ditekan ulang pada produk yang sudah di-like sebelumnya.

- **Method:** POST
- **URL Endpoint:** /api/produk/{id_produk}/toggle-like
- **Headers:** Authorization: Bearer {token} (Wajib ada)
- **Response Berhasil (200 OK):**

\\\json
{
  "success": true,
  "message": "Product liked successfully",
  "data": {
    "is_liked": true,
    "total_likes": 143
  }
}
\\\

*(Catatan: Pesan message bisa berupa "Product liked successfully" atau "Product unliked successfully" tergantung kondisi akhirnya, sedangkan objek data dapat Anda pergunakan secara langsung untuk mengupdate *state UI* jumlah text total_likes dan warna button pada perangkat secara instan).*

Silakan integrasikan fitur API ini pada komponen \produk_card.dart\, \produk_terlaris_card.dart\, dan \layout_detail_product.dart\. Beritahu kami jika menemui kendala dalam *parsing* di sisi Mobile/Flutter.

# Report: Implementasi Fitur Foto Profil Toko
**Tanggal:** 24 September 2026
**Kepada:** Tim Frontend
**Dari:** Tim Backend

Halo Tim Frontend,

Permintaan penambahan kolom foto/logo khusus untuk toko telah berhasil direalisasikan. Berikut adalah pembaruan yang kami lakukan di sisi Backend:

## 1. Skema Database
- Telah ditambahkan kolom baru bernama oto_toko pada tabel users.
- Kolom ini dapat digunakan untuk menyimpan nama file logo toko, terpisah dari foto profil *user* reguler.

## 2. API Pendaftaran / Update Toko
- Pada *endpoint* POST /api/user/input-store/{id_user}, kami telah membuka dukungan *upload file* untuk form dengan *key* oto_toko.
- Tipe file yang diizinkan adalah *image* (jpeg, png, jpg) dengan batas maksimal 2048 KB (2MB). File ini akan otomatis disimpan di server dan nama filenya akan dicatat pada kolom oto_toko.

## 3. Pembaruan Endpoint API Produk (Response Payload)
Pada seluruh endpoint API yang merender/menampilkan produk (seperti list produk, pencarian, detail produk, dsb.), *key* JSON "foto_toko" kini mengembalikan URL *asset* yang valid, alih-alih menggunakan foto *user* biasa.

Jika toko belum mengunggah foto profil toko, *backend* akan otomatis mengirimkan URL placeholder-image.png agar tampilan UI di aplikasi tidak rusak.

**Contoh Response Terkini:**
\\\json
{
  "id_produk": 1,
  "nama_produk": "Tenda Eiger",
  // ... field lainnya ...
  "nama_toko": "Eiger Store",
  "rating_toko": 4.8,
  "foto_toko": "https://domain.com/assets/image/customers/logo_toko/1630000000_eiger.png"
}
\\\

Fitur ini sudah bisa segera digunakan di Frontend. Mohon dipastikan saat pendaftaran/edit toko dari aplikasi, *multipart/form-data* untuk oto_toko berhasil terkirim.

Terima kasih atas kerja samanya!
