# Report Permintaan API Fitur Likes & History Komentar User
**Tanggal**: 10-10-2026

**Konteks Kendala & Fitur Baru:**
Sesuai permintaan dari tim frontend untuk menambahkan dua API baru guna menunjang fitur di halaman profil user (Profile):
1. **Tab Produk Disukai (Likes)**
2. **Tab Riwayat Komentar (Feedback)**

**Detail API yang telah diimplementasikan:**

1. **Endpoint Get Liked Products**
   - **Method:** `GET`
   - **URL/Endpoint:** `/api/user/likes`
   - **Header:** `Authorization: Bearer <token>`
   - **Response JSON:**
     ```json
     {
         "message": "success",
         "data": [
             {
                 "id_product": 1,
                 "nama_product": "Tenda Eiger 4P",
                 "harga": "35000.00",
                 "rating_rata_rata": "4.5",
                 "gambar_product": "http://localhost:8000/assets/image/produk/default.png"
             }
         ]
     }
     ```

2. **Endpoint Get Feedback/Komentar History**
   - **Method:** `GET`
   - **URL/Endpoint:** `/api/user/feedbacks`
   - **Header:** `Authorization: Bearer <token>`
   - **Response JSON:**
     ```json
     {
         "message": "success",
         "data": [
             {
                 "id_feedback": 10,
                 "id_product": 2,
                 "nama_product": "Carrier Consina 60L",
                 "gambar_product": "http://localhost:8000/assets/image/produk/default2.png",
                 "rating_diberikan": 5,
                 "komentar": "Barang sangat terawat, pelayanan juga memuaskan.",
                 "tanggal_ulasan": "2026-10-10 10:30:00"
             }
         ]
     }
     ```

# Report Permintaan API Fitur Ulasan (Rating & Feedback) Produk
**Tanggal**: 10-10-2026

**Konteks Kendala & Fitur Baru:**
Tim frontend membutuhkan API untuk mengirim ulasan produk (rating dan komentar) dari user serta mengambil daftar ulasan sebuah produk beserta informasi reviewer (nama dan foto) untuk ditampilkan di halaman detail produk.

**Detail API yang Telah Diimplementasikan:**

1. **Endpoint Submit Review/Ulasan**
   - **Method:** `POST`
   - **URL/Endpoint:** `/api/produk/{id_produk}/review`
   - **Header:** `Authorization: Bearer <token>`
   - **Body/Payload:**
     ```json
     {
         "rating": 5,
         "ulasan": "Barang sangat bagus dan terawat."
     }
     ```
   - **Response JSON:**
     ```json
     {
         "message": "Ulasan berhasil dikirim."
     }
     ```

2. **Endpoint Get Product Reviews**
   - **Method:** `GET`
   - **URL/Endpoint:** `/api/produk/{id_produk}/reviews`
   - **Response JSON:**
     ```json
     {
         "message": "success",
         "data": [
             {
                 "id_rating": 1,
                 "id_user": 10,
                 "nama_user": "John Doe",
                 "foto_user": "http://localhost:8000/assets/image/customers/profile/user1.jpg",
                 "rating": 4,
                 "ulasan": "Sangat membantu untuk camping.",
                 "tanggal_ulasan": "2026-10-10 14:00:00"
             }
         ]
     }
     ```

# Report Permintaan API Fitur Upload Foto pada Ulasan (Review) Produk
**Tanggal**: 10-10-2026

**Konteks Kendala & Fitur Baru:**
Tim frontend telah mengimplementasikan UI interaktif untuk mengirimkan ulasan (rating, teks, dan foto) di halaman detail produk. Namun, API `POST /api/produk/{id_produk}/review` saat ini hanya menerima `rating` dan `ulasan` dalam format JSON, belum mendukung pengiriman file gambar/foto.

Kami membutuhkan dukungan untuk mengunggah foto ulasan agar pengguna dapat menyertakan bukti gambar saat memberikan ulasan.

**Detail Penyesuaian API yang Telah Diimplementasikan:**

1. **Endpoint Submit Review/Ulasan (Diperbarui)**
   - **Method:** `POST`
   - **URL/Endpoint:** `/api/produk/{id_produk}/review`
   - **Header:** `Authorization: Bearer <token>`
   - **Content-Type:** `multipart/form-data`
   - **Body/Payload (Form Data):**
     - `rating`: integer (1-5, wajib)
     - `ulasan`: string (opsional)
     - `foto`: file gambar (opsional, max 2MB, format: jpg, jpeg, png)
   - **Response JSON (Success):**
     ```json
     {
         "message": "Ulasan berhasil dikirim."
     }
     ```

2. **Endpoint Get Product Reviews (Diperbarui)**
   - **Method:** `GET`
   - **URL/Endpoint:** `/api/produk/{id_produk}/reviews`
   - **Penyesuaian:** Tambahkan field `foto_ulasan` pada response data ulasan (bisa berupa string URL, atau array jika nanti mendukung banyak foto).
   - **Contoh Response JSON:**
     ```json
     {
         "message": "success",
         "data": [
             {
                 "id_rating": 1,
                 "id_user": 10,
                 "nama_user": "John Doe",
                 "foto_user": "http://localhost:8000/assets/image/customers/profile/user1.jpg",
                 "rating": 4,
                 "ulasan": "Sangat membantu untuk camping.",
                 "foto_ulasan": "http://localhost:8000/assets/image/reviews/1715423145_review1.jpg",
                 "tanggal_ulasan": "2026-10-10 14:00:00"
             }
         ]
     }
     ```
